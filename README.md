# e-Property demo

A Next.js marketing demo for a property platform. The home page walks through three sides of the product: landlords listing a property, agents matching clients, and people looking for a home. Listing cards and description cards are the main UI.

This is the earlier demo. The fuller product site is [epropertywebsite](https://github.com/Oreoluwaibk/epropertywebsite).

## Stack

Next.js (Pages Router), React, TypeScript, Tailwind CSS, Ant Design, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The home page is `src/pages/index.tsx`.

`npm run build` then `npm start` runs the production server.
